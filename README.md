# Kuber 3D  
**Кроссплатформенное учебное приложение для построения и визуализации геометрических фигур в 3D-пространстве.**

Kuber 3D — это учебно-практический ИТ-проект, предназначенный для изучения стереометрии с помощью интерактивных 3D-моделей.
---

## 🔧 Технологии проекта

### **Основная версия**
- **C++ + OpenGL** — основное настольное приложение  
- Работает на Windows и Linux  
- Включает 3D-сцену, управление камерой, построение фигур
