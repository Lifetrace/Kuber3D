# Kuber 3D  
**Кроссплатформенное учебное приложение для построения и визуализации геометрических фигур в 3D-пространстве.**

Kuber 3D — это учебно-практический ИТ-проект, предназначенный для изучения стереометрии с помощью интерактивных 3D-моделей.  
Проект содержит несколько независимых реализаций: настольную версию на Java, веб-версию на JavaScript (Three.js) и экспериментальную C++-песочницу.

---

## 🔧 Технологии проекта

### **Основная версия**
- **Java + JavaFX** — основное настольное приложение  
- Работает на Windows и Linux  
- Включает 3D-сцену, управление камерой, построение фигур и дерево объектов

### **Web-версия (демо)**
- **JavaScript + Three.js**
- Работает в браузере без установки
- Позволяет демонстрировать базовые 3D-фигуры и вращение сцены

### **Дополнительная версия**
- **C++ / Qt / OpenGL** — экспериментальный модуль (не входит в основной объём проекта)
