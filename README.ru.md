# Kuber3D

**Kuber3D** — это лёгкая интерактивная 3D-песочница по геометрии, созданная для обучения и демонстрации стереометрии.  
Она позволяет создавать и редактировать простые 3D-фигуры с помощью **точек, рёбер и граней**, рассматривать построения под любым углом камеры и выполнять базовые геометрические операции (углы, деление отрезков, перпендикуляры и т. п.). :contentReference[oaicite:0]{index=0}

Проект написан на **C++** с использованием **OpenGL**, **GLFW**, **GLM** и **Dear ImGui**.

---

## Возможности

- **3D-окно просмотра с орбитальной камерой**
  - плавное наведение камеры на цель и вращение
  - сетка для ориентации в пространстве

- **Построение на основе точек**
  - добавление точек и соединение их линиями
  - создание граней/четырёхугольников для отображения объёма
  - выбор объектов и их редактирование

- **Редактирование и операции (упор на клавиатуру)**
  - выбор/выделение мышью (picking)
  - соединение / разъединение точек линиями
  - деление отрезка в заданном отношении
  - создание точки на плоскости (плоскость задаётся 3 точками)
  - построение перпендикуляра от точки к плоскости

- **Измерение углов**
  - создание угла по 3 выбранным точкам
  - визуализация дугой

- **Рендеринг**
  - залитые грани + каркасные линии (wireframe)
  - пунктирные скрытые линии (рендеринг с учётом глубины)
  - UI-оверлей (ImGui)

- **Встроенные пресеты**
  - куб
  - пирамида
  - тетраэдр
  - окружность (WIP / экспериментально)

## Управление

- `TAB` — переключить **режим редактирования (Edit Mode)**
- `ЛКМ + перетаскивание` — вращение камеры
- `ЛКМ` (в Edit Mode) — выбрать точки  
  - `SHIFT` — мультивыбор
- `DELETE` — удалить выбранные точки
- `J` — соединить 2 выбранные точки линией
- `CTRL + J` — разъединить/удалить линию между 2 выбранными точками
- `S` — разделить отрезок  
  - выбрать 2 точки, затем ввести отношение `a` и `b`
- `P` — создать точку на плоскости  
  - выбрать 3 точки, задающие плоскость
- `R` — построить перпендикуляр от точки к плоскости  
  - выбрать **1 точку вне плоскости** + **3 точки на плоскости**
- `V` — навести камеру (target) на выбранную точку
- `G` — построить линию в грани по логике пересечений (расширенный инструмент / WIP)
- `A` — создать угол (выбрать 3 точки)

## Как устроено (в общих чертах)

Kuber3D хранит геометрию в динамических буферах (позиции точек, цвета, индексы).  
Взаимодействие пользователя основано на screen-space picking: 3D-точки проецируются в экранные координаты, и выбирается ближайшая точка в пределах заданного радиуса (в пикселях). Операции редактирования изменяют данные геометрии и при необходимости пересобирают GPU-буферы. :contentReference[oaicite:1]{index=1}

## Сборка / запуск

Шаги сборки зависят от окружения и toolchain (Visual Studio / MinGW и т. п.).  
Проект использует OpenGL + GLFW и слой интерфейса на ImGui.

Типовые зависимости:

- OpenGL
- GLFW
- GLM
- Dear ImGui
